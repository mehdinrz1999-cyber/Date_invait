# سایت دعوت به قرار ❤️

این پروژه یک سایت موبایل‌فرندلی است که پارتنرت به چند سؤال جواب می‌دهد و جواب‌ها به تلگرام شما ارسال می‌شود.

## اجرا
1. Node.js نصب باشد.
2. داخل پوشه پروژه:
   npm install
3. متغیرهای محیطی را تنظیم کن:
   - TELEGRAM_BOT_TOKEN = توکن BotFather
   - TELEGRAM_CHAT_ID = آیدی چت خودت
4. اجرا:
   npm start
5. سایت روی http://localhost:3000 باز می‌شود.

## نکته امنیتی
توکن ربات را داخل فایل HTML قرار نده. فقط روی سرور به‌صورت Environment Variable نگه دار.

## گرفتن CHAT_ID
به رباتت یک پیام بده، سپس با API getUpdates تلگرام می‌توانی chat id را پیدا کنی.
